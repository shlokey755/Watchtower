# Watchtower

An interactive 3D web experience built with **Three.js**, featuring a floating island model (`watchtower.glb`), smooth camera flight paths, custom section navigation, and dynamic lighting effects.

## Features

* **Interactive 3D Scene:** Explore the floating island model using custom cinematic viewpoints.
* **Guided Navigation:** Step through predefined sections (Overview, Crystals, Base, Aerial) via keyboard shortcuts, mouse wheel, or UI buttons.
* **Cursor & Particle Effects:** Features cursor-following lights, floating background motes, and interactive click-to-fly surface selection.
* **Smooth Transitions:** Custom easing animations for seamless camera interpolation.

## Tech Stack

* **Three.js** (WebGL 3D library)
* **GLTFLoader** & **OrbitControls**
